BYOKGPT 🤖

Your AI. Your API Keys. Your Control.

BYOKGPT is a personal AI chat app that lets you connect your own API keys and chat with supported AI models.

✨ Features

- 🤖 AI chat with supported providers like Gemini, OpenAI, and Claude
- 🔑 Bring Your Own API Key (BYOK)
- 🌐 Separate in-app browser mode
- 📎 File and image support (where implemented)
- 🎨 Clean, modern dark UI
- 🔒 Privacy-focused design

🚀 Getting Started

1. Download the APK from GitHub Releases.
2. Open the app and configure your AI provider.
3. Enter your own API key.
4. Select a model and start chatting.

Note: AI API usage may incur charges from your selected provider.
